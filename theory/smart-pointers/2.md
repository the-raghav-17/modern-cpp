- There is a critical flaw with the code that we wrote in 1.cpp. If we create a pointer that points to the same resource, and accidentally free it, it will lead to a double free() bug.

```cpp
int main()
{
    My_ptr<Resource> ptr{ new Resource() };
    My_ptr<Resource> ptr2{ ptr };

    // The allocated resource will get freed twice;
    // once when ptr2 exits the scope and once when
    // ptr exits the scope
}
```

In 4.cpp file, we created a simple Smart pointer class with support for move semantics. Although this is better than the previous implementation, it still has its own shortcomings.

The biggest of which is that when passing the pointer to a function, we sometimes want it to borrow the pointer instead of being its owner. The function will deallocate the resources pointed by the pointer, no matter what.

And the original pointer pointer we passed to the function will also be invalidated. This is not what we want all the times.
